# Домашная работа 6

## Папка storage

В этой папке соответственно описан докер, а также скрипты для запуска и остановки контейнера.

## Миграции

1) Первая миграция создает саму бд
2) Вторая - кастомная, заполняет первичными данными

### Применение
Для запуска проекта и применений миграций описан Makefile, через который можно проверить миграции и мигрировать их через `makemigration`
и `migrate` соответственно.

## Некоторые особенности

Так как я использовал viewsets.ModelViewSet все простые кастомные действия для получения легковесных данных уже были реализованы автоматически и для User, и для Post. Соответственно, кроме этого я никаких методов не делал.
